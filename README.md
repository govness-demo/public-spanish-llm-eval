# Public-sector Spanish evaluation suite

Benchmark and scripts that test language models on public-sector Spanish: procedures, forms and legal notices.

## Overview

Three thousand graded tasks drawn from public procedures across the region, with scripts to run them against any model and compare results.

## Interfaces

Protocol: `cli`. Languages: es.
